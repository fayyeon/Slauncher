# Slauncher

A lightweight and minimalist Android launcher with one-hand reachability principles.

For my personal-usage only, that's why I'm trying to make it as simple as possible. If you want to add your own additional features, you can fork it.

## Features
- **One-Handed Reachability**: App list starts at the middle of the screen for effortless one-handed thumb reach.
- **Multipurpose Wallpaper Scrim**:
  - In **Dark Mode**: Tap "Darken Wallpaper" to dim the wallpaper for white text contrast.
  - In **Light Mode**: Tap "Lighten Wallpaper" to brighten the wallpaper for black text contrast.
- **Double Tap to Lock**: Double tap anywhere on the screen or empty space to turn off and lock the display (uses Android Accessibility Service API, keeping fingerprint and biometric unlock intact).
- **Bottom-Anchored Search**: Search results appear directly above the search bar for fast launching.
- **Ultra Lightweight**: Optimized with R8 shrinking and minification (~900 KB APK).
